# Zhide Zhong · Academic homepage

Static academic website using Jon Barron’s original template.

Publish the root of the `main` branch with GitHub Pages. `.nojekyll` preserves the static files as provided.

- `index.html`: biography, education, and page structure.
- `publications.json`: the single publication list and media links.
- `app.js`: search, citations, and demo controls.
- `stylesheet.css`: original template CSS; fonts are served locally.
- `style.css`: accessibility and responsive additions.
- `assets/`: original profile and research visuals, local fonts, bibliography, and one short demo clip. Font licenses are included in `assets/fonts/`.

No CV, research-topic filters, first-author filters, backend, analytics, or external font requests.
